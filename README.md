## `01` — Sobre

```ts
const arthur = {
  stack:      ["React", "TypeScript", "Node.js", "Java + Spring", "PostgreSQL"],
  foco:       "interfaces claras, funcionais e consistentes",
  filosofia:  "lógica objetiva + boas práticas de design",
  atualmente: "construindo plataformas que precisam escalar de verdade",
  estética:   "flexível — do minimalista ao experimental",
};
```

Sou **Full Stack** com domínio forte em **UI/UX**: desenho e implemento interfaces que fazem sentido pra quem usa, não só pra quem olha. Transito confortavelmente entre frontend e backend, com experiência sólida em bancos relacionais — especialmente **PostgreSQL**.

Entre os projetos que me formaram: uma **API RESTful completa para gerenciamento de biblioteca**, com modelagem de banco, regras de negócio, autenticação e um frontend próprio consumindo essa API de ponta a ponta.

## `05` — Sobre estilo visual

> Não sigo um único padrão estético.
>
> Trabalho confortavelmente do minimalista ao carregado, do clássico ao experimental.
> **Cada projeto pede uma identidade própria — e meu trabalho é encontrar a certa, não impor a minha.**

A única coisa inegociável é a qualidade de **UI/UX**: clareza, consistência e intenção em cada decisão.
